# Working Agreement

## Our starting protocol

We reviewed AI outputs before using them, making sure the code would not break the rest of the code and that it ran smoothly. "After all, it has your name on it" was a quote we kept using.

## What actually happened

We kept making sure that we used AI changes without breaking the code and data. Early on, we didn't always check non-code suggestions as carefully.

## What changed and why

Some of us moved from text to voice mode, because it was easier for some of us to think out loud instead of typing.
